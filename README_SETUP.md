# คู่มือการติดตั้งและใช้งาน: ระบบรายงานนับสต็อกสินค้า หจก.สิรณัฐการค้า

โครงการสำหรับส่งอาจารย์ เขียนด้วย **PHP (PDO) + MySQL + Bootstrap 5** (รวมระบบทั้งหมดในไฟล์เดียว `login.php`)

---

## 📁 ไฟล์สำคัญในโปรเจกต์
1. `login.php` : ไฟล์โปรแกรมหลัก (PHP + Bootstrap 5 + ระบบ Session + ฟอร์มพนักงาน + แผงควบคุมแอดมิน)
2. `database.sql` : สคริปต์สร้างฐานข้อมูล `sirinath_inventory` พร้อมตารางและข้อมูลตั้งต้น 5 รายการ

---

## 🛠️ ขั้นตอนการติดตั้งบน XAMPP / AppServ

### ขั้นตอนที่ 1: ติดตั้งฐานข้อมูล (MySQL / phpMyAdmin)
1. เปิดโปรแกรม **XAMPP Control Panel** แล้วกด **Start** ที่โมดูล **Apache** และ **MySQL**
2. เปิดเว็บบราวเซอร์ ไปที่: `http://localhost/phpmyadmin`
3. ไปที่แท็บ **Import (นำเข้า)** ด้านบน
4. กดปุ่ม **Choose File (เลือกไฟล์)** แล้วเลือกไฟล์ `database.sql` จากโปรเจกต์
5. กดปุ่ม **Import (นำเข้า)** ด้านล่างสุด 
   * ระบบจะสร้างฐานข้อมูล `sirinath_inventory` พร้อมตาราง `users`, `products`, `stock_counts`, `stock_movements` ให้อัตโนมัติ

### ขั้นตอนที่ 2: วางไฟล์โปรเจกต์
1. ไปที่โฟลเดอร์ติดตั้ง XAMPP (โดยปกติคือ `C:\xampp\htdocs\`)
2. สร้างโฟลเดอร์ชื่อ `sirinath`
3. คัดลอกไฟล์ `login.php` ไปวางไว้ในโฟลเดอร์ `C:\xampp\htdocs\sirinath\`

### ขั้นตอนที่ 3: เปิดใช้งานระบบ
1. เปิดเว็บบราวเซอร์ เข้าลิงก์:
   ```text
   http://localhost/sirinath/login.php
   ```

## 📋 ข้อมูลสินค้าเริ่มต้น 5 รายการ
1. `P-001` : สายฉีดชำระสแตนเลส 304 (หมวดอุปกรณ์ห้องน้ำ) - จำนวนสต็อกในระบบ: 45 ชิ้น
2. `P-002` : ก๊อกน้ำอ่างล้างหน้าเซรามิกวาล์ว (หมวดอุปกรณ์ห้องน้ำ) - จำนวนสต็อกในระบบ: 30 ชิ้น
3. `P-003` : สีสเปรย์อเนกประสงค์ สีดำเงา (หมวดเคมีภัณฑ์และสี) - จำนวนสต็อกในระบบ: 120 ชิ้น
4. `P-004` : สกรูเกลียวปล่อย 1 นิ้ว (หมวดฮาร์ดแวร์และสกรู) - จำนวนสต็อกในระบบ: 200 ชิ้น
5. `P-005` : แปรงทาสี ขนเคมี 2 นิ้ว (หมวดอุปกรณ์ทาสี) - จำนวนสต็อกในระบบ: 85 ชิ้น
